**Organization:** TSW

**Roles:** Software Architect, Backend Developer  
**Period:** June 2015 – March 2016

## Context

Develop the backend of a travel-package website, connecting its web publishing layer to existing business systems and supporting a high-load application.

## My contribution

- Developed backend functionality and integrated WordPress with custom APIs backed by AS400 systems.
- Worked on application development and optimization for high-load usage.
- Contributed to a multinode application architecture using a message queue.
- Worked on the deployment system using Git and Ansible.

## Engineering focus

Bridging web applications and established enterprise systems, while considering deployment automation and application load as part of the same engineering problem.

This describes my contribution while working at TSW, not sole authorship of the platform. The current client website may differ from the version described here.

**Organization:** DigitalMind  
**Client:** Graniti Fiandre  
**Roles:** Software Architect, Backend Developer, IT Operations  
**Period:** October 2018 – October 2019

## Context

Build an internal tool for organizing catalogue and marketing images, taking into account both the existing media archive and the client's infrastructure.

## My contribution

- Collected requirements and translated them into software solutions.
- Reviewed, audited, configured and optimized the infrastructure supporting the project.
- Analyzed the existing media archive.
- Integrated the application with existing authentication management and shared storage.
- Worked on a multinode architecture with decoupled services.
- Automated batch processing using systemd.

## Engineering focus

Designing a custom application around an organization's actual data, access controls and operational constraints, rather than treating infrastructure integration as an afterthought.

This project was delivered through DigitalMind; the responsibilities above describe my contribution.

**Type:** Historical open-source project  
**Status:** Archived

## Context

Collect recurring WordPress theme-development patterns in a reusable foundation, rather than rebuilding the same functionality for each website.

## Implementation

- A utility collection originally designed to work as a parent theme.
- PHP classes for common website functionality.
- Registered JavaScript assets, reusable template parts and theme templates.
- Less mixins and supporting frontend assets.
- A child-theme example demonstrating how to use the shared foundation.

## Engineering focus

An early example of the same approach I apply to infrastructure and tooling today: identify repeated work and extract reusable building blocks.

These repositories are archived and document historical work. They are not presented as maintained tooling for current WordPress installations.
